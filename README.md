# MA 131 · Shape of Graph + Optimization Test Review

A static, GitHub Pages-ready HTML learning activity modeled on the supplied Mastery Pathway example.

## Contents
- **30-question diagnostic**: 3 questions per topic.
- **10 targeted modules**: strategy notes, examples, and 4-question checks (40 practice questions).
- **30-question final assessment**: distinct questions for measuring improvement.
- **100 total original questions**, step-by-step explanations, an original interactive-worksheet-style graph of f′, a math toolkit, growth report, local progress saving, import/export, and reset.
- Topics: critical numbers; increasing/decreasing; relative extrema; concavity; inflection points; interpreting a graph of f′; second derivative test; absolute extrema and domain; objectives/constraints; optimization applications (garden, can, fabric box, orchard).

## GitHub Pages publishing
1. Create a public GitHub repository.
2. Upload **index.html**, **style.css**, **data.js**, and **app.js** to the repository root, using these exact filenames.
3. Go to **Settings → Pages → Deploy from a branch**, choose **main** and **/(root)**, then Save.
4. Open the URL GitHub Pages provides. If you initially see a README, refresh after the deployment completes.

You can also open `index.html` locally. No build system, server, account, or external dependencies are required.

## Notes
Progress is stored in the browser's `localStorage`; use Export/Import to transfer progress to another device. Retaking the diagnostic clears prior practice and final scores. Scores are raw practice scores, not official course-grade predictions.

The graph-based questions use a **new original graph of f′(x)=x²−4**, not a reproduction of an unspecified textbook graph. Source handouts inform the topics and example contexts; the review questions are original.
